FIX: "Fatal process out of memory" / jest-worker crash
====================================================

DO NOT run:  npx.cmd expo start
USE instead: npm.cmd run start
         or: START-EXPO-GO.bat

Before starting:
1. Task Manager -> end extra Node.js processes
2. Close Electron, browsers, desktop npm start
3. Keep ONLY: backend window + expo window
4. Do NOT use --clear (rebuilds cache, uses more RAM)

Start backend (separate CMD):
  cd ..\backend
  npm.cmd run dev

Start mobile (CMD in mobile folder):
  set NODE_OPTIONS=--max-old-space-size=8192
  set METRO_MAX_WORKERS=1
  npm.cmd run start

When prompted: Down arrow + Enter = Proceed anonymously

If still OOM:
- Reboot PC
- Windows: increase virtual memory (page file) to 16GB+
- Run: node scripts/patch-jest-worker.js
- Then npm.cmd run start again

Scan QR in Expo Go. URL: exp://192.168.148.95:8081 (or port shown in terminal)
