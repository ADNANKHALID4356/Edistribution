HOW TO RUN THE APP
==================

STEP 0 - Check Node (must be v22, NOT v24)
------------------------------------------
    node -v
Must show v22.x (not v24).


ELECTRON (desktop window) - RECOMMENDED
---------------------------------------
Double-click:  RUN-TODAY.bat   or   RUN-APP.bat

- Starts backend on port 5000
- Builds desktop\build once (no port 3000 needed)
- Opens Electron from the production build

Do NOT run "npm run electron" alone unless build\index.html exists
or you already have "npm start" running on port 3000.

If build fails (out of memory): close Chrome/Cursor/extra Node apps,
reboot, run RUN-TODAY.bat again.
