## 6) MULTI-TENANT ISOLATION SECTION (IMPORTANT)

### Heading
**Salesman-Isolated Workspaces for Data Security and Accountability**

### Body
Each salesman operates with an isolated account scope (`salesman_id`-based visibility).  
This tenant-style model ensures one salesman cannot access another salesman’s operational data, improving security, discipline, and auditability.

### Key Points
- Identity-scoped field operations  
- Prevents cross-salesman data leakage  
- Improves accountability per salesperson  
- Supports safe scaling to larger sales teams
